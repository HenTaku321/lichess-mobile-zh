## 分页与页面行为

`XiangqiPage<T>` 保存 items/currentPage/nextPage/previousPage/可空 totalPages；页数未知不伪造。
新增 loadChatsPage、loadMessagesPage、通知与好友页读取，旧调用保留第一页兼容入口。
私信、通知分别 fork；超时、断链、取消或无法解析响应后废弃旧 client/订阅，再握手后服务下一项。
请求关联账号代际／资源／页码／刷新代际，续 token 保内容，换号／退出隔离所有旧状态。
私信 NoAck 不变，通知按实测成功事件处理；发送与标读不自动重放，不编造 message server ID。

联系人／通知／好友／资料记录追加更多，私信从最旧处加载历史；赛事排名使用前后页控件。
更多失败保内容和游标，局部失败只重试对应操作；合并联系人健康源先显示，失败源保留旧内容。
页码式刷新保当前页，追加式刷新重读已加载范围并成功后替换；返回保持筛选／页码／滚动锚点。
刷新／分页不丢输入草稿或抢焦点；身份切换清理私有草稿；无证据的上游能力不能伪造通过。

## 用户锁定的完整视觉矩阵

- 每个适用状态：480×480／1280×720／1920×1080 × 中英 × 深浅 × 字缩放 1／2 × DPI 1／2，共 48 组。
- 所有适用离散偏好全量相乘，不用定向或 pairwise 抽样替代。
- 连续参数固定网格：亮度 0.2～1.4 步长 0.1、色相 0～360 步长 30°；已离散的滑杆按全部界面档位。
- 两边同配置／阶段，以真实操作进入状态；只模拟网络、引擎和平台边界，不替换整个 controller。
- 开启 real rating preferences，并断言实际偏好与阶段生效；注册有意棋盘／棋子／规则差异。
- 同布局角色几何误差 ≤1 逻辑像素；保存两侧 DPI 原图、角色差异图、请求及几何元数据。
- 评估反馈包括用户落子、人机回复与下一用户输入；主观视觉与原生声音／触觉结论单独记录。

## 手动批次、资源上限和证据

- 独立 workflow_dispatch；每批 ≤1024 对、每分片 ≤64 对、最多16分片、并发4、每片30分钟。
- 组合惰性枚举、精确整数计数，不把百万级组合在内存中一次展开。
- 固定候选 SHA／注册表／渲染依赖指纹；变化即使旧覆盖失效，不自动触发后续批次。
- 产物保留90天；缺图、跳过、过期证据、编译或夹具错误不计通过。
- 报告通过／失败／未运行／协议缺证据，避免用单批绿或图片数量冒充全覆盖。
- 只下载必要小索引和问题配对，不自动搬运全部图片；本批不构建／安装新包。
